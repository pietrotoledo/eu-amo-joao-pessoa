# Eu amo João Pessoa

Site de apresentação dos serviços de gestão de imóveis por temporada em João Pessoa.

## Publicação

Site estático em HTML, CSS e JavaScript. Os arquivos da raiz podem ser publicados diretamente, sem etapa de compilação. GitHub Pages usa a branch `main`, pasta raiz.

## Conteúdo

O protótipo utiliza imagens ilustrativas geradas com IA. A identidade visual e o conteúdo comercial continuam em validação. Os colaboradores aparecem no rodapé. O contato principal é pelo WhatsApp.

## Dependências

GSAP 3.15.1 e ícone WhatsApp do Bootstrap Icons 1.13.1, com licenças mantidas na pasta `vendor`. Mapa incorporado do OpenStreetMap com atribuição.
